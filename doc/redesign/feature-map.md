# Feature-to-source map

Inspection baseline: `4953f0be3ea61dd5fc62f2c333e540d2b166ccbc` (VLC 4.0 development). This is a static source/design audit. Existing code means an implementation or API was found, not that it has passed runtime verification on this machine. Every target below is pending implementation/verification in the redesign.

Source paths are relative to the repository root. Mac paths below `modules/gui/macosx/` and Windows paths below `modules/gui/qt/` refer to separate interfaces around common VLC core capabilities.

## Shared persistence and feature services to design

1. **Subtitle associations and scoped presets:** schema version, media/folder identity, moved files, preferred language fallback, duration/format matching, import preview, per-track delay, precedence/reset and privacy clearing. Reuse media-library storage where its API permits; do not put one database implementation in Cocoa and an incompatible one in Qt.
2. **Cue timeline:** accessible cue list for external and embedded text tracks, conversion to presentation timestamps, drag/snap semantics, delay vs subtitle-rate changes, memory bounds and unsupported bitmap tracks.
3. **Preview caches:** seek thumbnails and audio waveform generation with bounded storage, background scheduling, cancellation, stale-file invalidation and no interference with normal playback.
4. **Profiles:** distinguish appearance/layout, playback presets and global configuration. Store semantic action IDs, not positions in a particular platform's view hierarchy. Existing Qt toolbar profiles are reusable infrastructure, not proof of whole-app profile parity.
5. **Timer and capability model:** common meanings for sleep timer and availability of seek/rate/reverse/record/HDR/output device actions. Surface limitations from actual capabilities instead of a decorative disabled control with no explanation.

These services may need common-core or media-library changes, but the audit does not pre-authorize a particular storage ABI or parser design. Select the narrowest compatible extension after building and testing the baseline.
